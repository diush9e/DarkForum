# 🌙 DarkForum - المنتدى الحديث

منصة نقاشات كاملة بتصميم داكن احترافي.

## ✨ الميزات
- 🔐 نظام مصادقة كامل
- 👤 ملفات شخصية
- 📝 مواضيع وتعليقات
- ❤️ إعجابات
- 💬 محادثات
- 🎨 تصميم داكن حديث

## 🚀 البدء
```bash
npm install
cp .env.example .env.local
# عدّل DATABASE_URL في .env.local
npx prisma db push
npm run dev
```

## 🛠️ التقنيات
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Prisma
- NextAuth.js
